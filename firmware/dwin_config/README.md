# DWIN DGUS Configuration

## Overview

The DWIN 7" V647 display is configured using DWIN DGUS Tool (Windows application provided by DWIN).

## VP (Variable Pointer) Mappings

| VP Address | Variable | Type | Scale |
|------------|----------|------|-------|
| 0x1000 | Speed | Integer | ×10 (so 250 = 25.0 km/h) |
| 0x1001 | Battery | Integer | 0–100 (%) |
| 0x1002 | Distance | Integer | ×10 (so 100 = 10.0 km) |
| 0x1003 | System State | Integer | 0=IDLE, 1=RUNNING, 2=CHARGING, 3=FAULT |

## UI Screens

### Main Dashboard
- Speedometer arc graphic (animated via VP 0x1000)
- Battery bar graphic (animated via VP 0x1001)
- Distance numeric field (VP 0x1002)
- Status indicator (color changes based on VP 0x1003)

## Configuration Files

The DWIN DGUS project files (`.dgus`, `.bin`, `.icl`) are not included in this repository. These are:
1. Large binary files
2. Generated by DWIN DGUS Tool
3. Not text-based

The UI design is documented here for reference. To rebuild:
1. Install DWIN DGUS Tool
2. Create project with 800×480 resolution
3. Design UI elements
4. Assign VP addresses per the table above
5. Export to SD card
6. Insert SD card into display; it auto-loads

## Notes

- UART baud rate must match: 115200
- Display must be powered with 12V DC
- Communication is unidirectional (Arduino → Display for writes)
- For touch input, DWIN sends frame on touch event
